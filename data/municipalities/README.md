# 市区町村人口データ

このフォルダは、人口ブラックジャックで使う市区町村カードのデータ置き場です。

- `municipalities.csv`: 収集・確認用の元データ
- `municipalities.js`: アプリが読み込む配信用データ

全国の市区町村（2,220件）を収録しています。出典は総務省「住民基本台帳に基づく人口、人口動態及び世帯数調査」（令和8年1月1日現在）です。政令指定都市の区（例: 札幌市中央区）や東京都特別区（例: 千代田区）も、市区町村と同格の1件として個別に含まれています。人口0人として集計される北方領土内の6村（色丹村、泊村など、現在日本の施政権が及んでいない地域）はゲームとして成立しないため除外しています。

出典URLを追加したい、またはより新しい時点のデータに更新したい場合は、`sourceUrl` 列を埋めてから同じ形式で差し替えてください。

## 列

- `id`: 総務省の団体コード（6桁）。市区町村名の日本語をローマ字化すると読みの揺れで衝突・誤変換のリスクがあるため、公式の一意コードをそのまま採用しています。ゲーム内では表示されず、内部の重複排除キーとしてのみ使われます。
- `prefecture`: 都道府県
- `municipality`: 市区町村名
- `population`: 人口。半角数字、カンマなし
- `category`: 抽選重みに使う人口帯
- `populationDate`: 人口の時点
- `sourceName`: 出典名
- `sourceUrl`: 出典URL

## カテゴリ

カテゴリはゲームバランス用の人口帯です。あとで人口値から再分類できます。

- `village_town`: 5万人未満
- `small_city`: 5万人以上10万人未満
- `mid_city`: 10万人以上20万人未満
- `large_city`: 20万人以上70万人未満
- `ordinance_city`: 70万人以上
